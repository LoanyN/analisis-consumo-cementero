# 📊 Análisis de Eficiencia Energética en Edificios Industriales
# Analisis Consumo Cementero
## Descripción
Análisis exploratorio de datos sobre eficiencia energética en edificios 
industriales, con enfoque en variables físicas que impactan el consumo 
de calefacción y refrigeración. Proyecto orientado a la toma de decisiones 
sostenibles en la industria de la construcción y materiales.

## Tecnologías utilizadas
- Python 3.12
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Hallazgos principales
- La **compacidad** es la variable más influyente en el consumo energético
- Edificios de mayor altura consumen significativamente más energía
- El consumo de refrigeración supera al de calefacción en todos los casos

## Estructura del proyecto
- `analisis.ipynb` — Notebook principal con el análisis completo
- `ENB2012_data.xlsx` — Dataset de eficiencia energética (UCI Repository)
- `grafica1_distribucion.png` — Distribución de consumo energético
- `grafica2_compacidad.png` — Impacto de compacidad en consumo
- `grafica3_correlaciones.png` — Mapa de calor de correlaciones
- `grafica4_altura.png` — Consumo promedio por altura
